OVER‑THE‑AIR UPDATE

อัปเดตเฟิร์มแวร์

ใช้ Arduino IDE หรือเครื่องมือที่รองรับ ArduinoOTA เพื่ออัปเดต SmartFarm โดยไม่ต้องถอดสาย USB

BEFORE YOU START

ตรวจสอบก่อนอัปเดต

◌อุปกรณ์ออนไลน์ESP8266 ต้องเชื่อม Wi‑Fi เดียวกับคอมพิวเตอร์ที่จะอัปเดต
⌁ไฟเลี้ยงเสถียรอย่าตัดไฟหรือรีสตาร์ตอุปกรณ์ระหว่างการอัปโหลด
✓ตรวจ source ให้พร้อมใช้ไฟล์ SmartFarm_V6_PRODUCTION.ino เวอร์ชันที่ผ่านการทดสอบแล้ว

ARDUINO IDE

ขั้นตอนอัปเดต

  1. เปิดไฟล์ SmartFarm_V6_PRODUCTION.ino
  2. เชื่อมคอมพิวเตอร์และ ESP8266 เข้ากับ Wi‑Fi เดียวกัน
  3. เลือกเมนู Tools → Port และเลือกพอร์ตเครือข่ายของ SmartFarm
  4. กด Upload และรอข้อความ OTA: END ใน Serial Monitor

SAFETY

หากอัปเดตไม่สำเร็จ

!อย่าทำซ้ำต่อเนื่องทันทีตรวจสถานะ Wi‑Fi ชื่ออุปกรณ์ และรหัส OTA ก่อนเริ่มใหม่
⌁ทางเลือกสำรองเชื่อมต่อ USB และแฟลชผ่านพอร์ต serial หากอุปกรณ์ไม่ปรากฏเป็น network port
