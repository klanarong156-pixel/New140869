Smart Farm V7.0 build and validation status

The most recent historical CI evidence in this repository predates the V7.0 source changes. It confirmed that the previous ESP8266 source compiled successfully, but it is not evidence that the modified V7.0 firmware compiles or behaves correctly.

Current source changes requiring validation
- Firmware version string is now V7.0.0-PRODUCTION-HARDENED.
- Switching from AUTO to MANUAL explicitly turns all relays OFF before accepting individual manual commands.
- Dashboard MQTT credentials were removed from source and must now be supplied by the operator in the browser.
- Dashboard pin-map content was aligned to the current firmware: DHT11=D2, DS3231 SDA=D3, DS3231 SCL=D4, relays D5–D8.

Required validation before production use
1. Compile SmartFarm_V6_PRODUCTION.ino for esp8266:esp8266:nodemcuv2 with the project libraries.
2. Flash a test NodeMCU and verify boot state: all relays are OFF.
3. Verify MQTT connect, retained relay/mode/schedule statuses, and DHT11 heartbeat.
4. Verify all four schedule slots for every relay in AUTO mode, including an overnight slot.
5. Verify a switch from AUTO to MANUAL turns every relay OFF and publishes their statuses.
6. Verify pump safety timeout and the 60-second MANUAL MQTT-loss cutoff on real hardware.
7. Verify OTA with a stable power supply and the configured OTA password.

The known build resource profile from the historical V6 compile was approximately 41% global RAM, 94% IRAM and 48% flash. IRAM headroom was limited, so the V7 compile result must be reviewed before new firmware is deployed.
