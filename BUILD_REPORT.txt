OTA และ safety
ArduinoOTA ใช้ hostname ที่สร้างจาก Chip ID และเปิดรับ OTA เมื่อมี `ota_pass` เท่านั้น มี callbacks สำหรับเริ่ม/ความคืบหน้า/จบ/ข้อผิดพลาด พร้อม error code ที่อ่านได้ ส่วน Web OTA ใช้ HTTP port 80, Basic Authentication (`admin` กับ OTA password), หน้า `/`, upload `POST /update` และ status `/api/status`; ตรวจ `.bin`, ขนาดและพื้นที่ sketch, ตรวจผล `Update.end()` และตอบ numeric error code/reason เมื่อผิดพลาด
ก่อน OTA จะปิดรีเลย์ทั้งหมด, ตัด MQTT/TLS และหยุด pump runtime หาก OTA ล้มเหลวจะคง relay lock ไว้จนกว่าจะตรวจสาเหตุและรีสตาร์ตเอง การอัปเดต HTTP ที่สำเร็จจะรอส่งคำตอบก่อนรีสตาร์ต; main loop ตรวจ restart timer ก่อน OTA early-return
Web OTA เป็น HTTP ไม่ใช่ HTTPS ให้ใช้เฉพาะเครือข่าย LAN ที่เชื่อถือได้และห้ามทำ port-forward ออก Internet

การเชื่อม Dashboard และ telemetry
คง relay pin และ MQTT topic contract เดิม; heartbeat เพิ่ม firmware/mode/relay/OTA status และ diagnostics; MQTT reconnect ใช้ exponential backoff สูงสุด 60 วินาทีและ socket timeout 5 วินาที โดยไม่ทำ TLS preflight ซ้ำทุก reconnect; DHT11 ส่งเฉพาะค่าจริงที่ finite ส่วนค่า null/สถานะ unknown ไม่ถูกแปลงเป็นศูนย์หรือ OFF; Dashboard ปิดคำสั่งควบคุมเมื่อ ESP ไม่มี heartbeat ล่าสุดและต้องยืนยันก่อนสั่งรีเลย์/ฉุกเฉิน
อัปเดต Service Worker/cache versions ให้ตรงกัน และไม่เปลี่ยน CSS/theme style4; ไม่มี Zone 2 ใน UI
