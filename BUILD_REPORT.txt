SMART FARM V7.2.1 OTA ACCESS + FAST CONNECT — BUILD REPORT
วันที่ตรวจสอบ: 2026-10-04 (UTC+7)

สรุป
- PlatformIO build สำเร็จสำหรับ NodeMCU 1.0 / ESP-12E (nodemcuv2), ESP8266 Arduino Core 3.1.2 และ platform espressif8266@4.2.0
- แก้ปัญหากรณี `ota_pass` ยังว่าง: `http://<IP-ของ-NodeMCU>/` แสดงหน้าคู่มือภาษาไทยแบบอ่านอย่างเดียว; upload และ API ยังคงบังคับ Basic Authentication (`admin` + `ota_pass`)
- ลดเวลาการเชื่อมต่อ: MQTT attempt แรกเริ่มทันทีเมื่อ Wi-Fi/TLS พร้อม; backoff เริ่ม 3 วินาทีและยังเพิ่มแบบ exponential สูงสุด 60 วินาที
- ถ้า DS3231 มีเวลาที่ valid จะใช้เวลานั้นตรวจสอบ TLS และเลื่อน NTP sync ไปหลัง MQTT เชื่อมต่อ; ถ้า RTC invalid/unavailable ยังคงต้องรอ NTP ก่อน TLS เพื่อไม่ลดความปลอดภัย
- ส่ง heartbeat ทันทีเมื่อ MQTT ต่อสำเร็จ และส่งทุก 2 วินาทีใน 60 วินาทีแรก จากนั้นกลับ cadence ปกติทุก 10 วินาที ใช้ topic/payload/retain contract เดิม
- Dashboard ยังคงไม่ถือ retained snapshot เพียงอย่างเดียวว่า ESP online จึงไม่เปิดใช้งานปุ่มควบคุมจากสถานะเก่าค้างใน broker
- ไม่เปลี่ยน pin map, รีเลย์, command topic, OTA authentication หรือ safety lock

การใช้งาน
1. เปิดหน้า OTA ของอุปกรณ์โดยตรง: `http://<IP-ของ-NodeMCU>/` บน LAN เดียวกัน (ไม่ใช่ `ota.html` บนเว็บ Dashboard)

3. เข้า URL อีกครั้งด้วย username `admin` และรหัสผ่าน `ota_pass` แล้วเลือก BIN นี้
4. ใช้เฉพาะ LAN ที่เชื่อถือได้ ห้าม port-forward พอร์ต 80 ออกอินเทอร์เน็ต

ข้อจำกัด
- ยังไม่ได้ flash หรือวัดเวลาเชื่อมต่อกับ NodeMCU จริง; ความเร็วจริงยังขึ้นกับ Wi-Fi, เวลา DS3231/NTP, DNS/TLS, อินเทอร์เน็ตและ HiveMQ Cloud
- เมื่อ Dashboard เปิดอยู่ก่อน ESP ต่อ MQTT จะเห็น heartbeat ทันที; Dashboard ที่เพิ่งเปิดภายใน 60 วินาทีหลังต่อสำเร็จควรได้ heartbeat สดภายในรอบไม่เกิน 2 วินาที ส่วนหลัง burst จะกลับไป heartbeat 10 วินาทีตามปกติ
- ต้องทดสอบ Wi-Fi, MQTT, DHT11, DS3231, รีเลย์ และ OTA กับบอร์ดจริงก่อนใช้งานจริง
- หน้า Dashboard `ota.html` รับเฉพาะ HTTPS gateway ตามแบบเดิม จึงไม่ใช่ URL สำหรับเปิดหน้า HTTP OTA ของตัวบอร์ดโดยตรง
