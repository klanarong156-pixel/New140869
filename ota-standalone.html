อัปเดตเฟิร์มแวร์ภายในเครือข่ายเดียวกับ ESP8266

อัปโหลด Firmware OTA

หน้านี้เป็นไฟล์เดียว ใช้เปิดจาก file://, http://localhost หรือเปิดตรงจาก ESP8266 เพื่อหลีกเลี่ยง Mixed Content จาก GitHub Pages HTTPS

!กำลังเปิดหน้านี้ผ่าน HTTPS Browser จะบล็อกการส่งจาก GitHub Pages HTTPS ไปยัง ESP8266 HTTP ให้ดาวน์โหลดไฟล์นี้แล้วเปิดแบบ file:// หรือเปิดผ่าน local HTTP server หรือเปิด http://IP-ของ-ESP/ โดยตรง
!ต้องอยู่ Wi‑Fi เดียวกับบอร์ด และ URL ต้องเป็น HTTP เช่น http://192.168.1.50 ห้ามใส่ /update ต่อท้าย URL
พร้อมใช้งานกรอก URL รหัสผ่าน และเลือกไฟล์ก่อนเริ่ม
  • 1.กดตรวจการเชื่อมต่อให้ได้สถานะ 200 ก่อน
  • 2.ตรวจว่ารีเลย์/ปั๊มปิดอยู่ และจ่ายไฟให้บอร์ดคงที่
  • 3.เริ่มอัปโหลดแล้วห้ามถอดไฟหรือปิดหน้านี้จนกว่าจะจบ
  • 4.รอ ESP8266 รีสตาร์ต แล้วตรวจ firmware, MQTT และรีเลย์หลังอัปเดต
ไม่ใช้ MQTT และไม่ส่ง credential ไปยัง server อื่น · Smart Farm
